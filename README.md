# 🎁 Whiff & Wrap

A beautifully crafted handmade gifts platform offering unique, personalized products for every occasion. Explore, customize, and order creative gift items online with a simple and smooth experience

## 📋 Overview

Whiff & Wrap is a modern e-commerce showcase dedicated to handmade gifts. Whether you're looking for personalized presents, artisanal creations, or custom-designed items, our platform connects you with unique handcrafted treasures.

### Key Features

- 🎨 **Unique Handmade Products** - Carefully curated selection of handcrafted gifts
- 🛍️ **Easy Browsing** - Smooth and intuitive shopping experience
- ✨ **Customization Options** - Personalize your gifts to make them special
- 💝 **Perfect for Every Occasion** - Find the ideal gift for birthdays, anniversaries, celebrations, and more
- 🚀 **Fast & Reliable** - Quick ordering and delivery process

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/sTharun5/WhiffAndWrap.git
cd WhiffAndWrap
```

2. Navigate to the frontend directory:
```bash
cd frontend
```

3. Install dependencies:
```bash
npm install
# or
yarn install
```

4. Start the development server:
```bash
npm run dev
# or
yarn dev
```

5. Open [http://localhost:5173](http://localhost:5173) in your browser to view it.
